Tenant Flow is designed to streamline maintenance operations within residential apartment complexes in Sri Lanka. The system enables tenants to report issues, property managers to assign tasks, maintenance staff to update progress, and tenants to make payments through a secure online gateway.


Technologies used:
     Frontend: React.js
     Backend:	Node.js + Express 
     Database: MongoDB Atlas
     Authentication: JWT
     Secure Payments : PayHere Sandbox to simulate live payment transactions without requiring real money, business registration, or complex banking integration

Note that: Property manager information is seeded to the database(Property managers cannot register to the system as  they act as the admins)
